## Структура проєкту

* `grammar/sipl.lark` — формальна БНФ-граматика мови SIPL.
* `src/sipl/` — ядро проєкту (`parser.py`, `ast_nodes.py`, `interpreter.py`, `trace.py`, `semantics.py`, `visualization.py`, `diagnostics.py`, `cli.py`).
* `examples/` — приклади програм мовою SIPL (`gcd`, `power`, `factorial`, `sum`, `max`, `infinite`).
* `conformance/` — незалежні еталонні сценарії та скрипт перевірки.
* `tests/` — набір автоматичних тестів `pytest`.

## Використання CLI

    sipl check examples/gcd.sipl
    sipl run examples/gcd.sipl --var A=12 --var B=18
    sipl run examples/infinite.sipl --max-steps 20
    sipl trace examples/sum.sipl --var N=3
    sipl semantics examples/max.sipl
    sipl parse examples/max.sipl --kind ast --format text
    sipl compare examples/power.sipl -o compare.html

Усі команди підтримують прапорець `--json` для структурованого виводу та символ `-` замість шляху до файлу для читання коду зі стандартного потоку вводу (`stdin`). Коди завершення: `0` — успіх, `1` — синтаксична помилка, `2` — помилка аргументів або файлу, `3` — помилка часу виконання.

## Як працює виконання та семантика

* **Цілі числа:** усі обчислення виконуються лише над цілими числами; оператор `/` дає цілу частину від ділення, а `%` — остачу.
* **Перевірка змінних:** якщо програма намагається використати змінну, якій ще не задано значення, виконання зупиняється з помилкою `undefined-variable`.
* **Захист від зациклення:** інтерпретатор рахує кожну виконану дію (присвоювання, `skip`, перевірку умови в `if` чи `while`) і зупиняє програму, якщо перевищено ліміт кроків (`--max-steps`).
* **Академічна нотація:** семантичні терми будуються автоматично з AST у форматі практикуму курсу (`AS^x`, композиція `•`, суперпозиції `S^1`/`S^2`, іменування `x⇒`, константи `n̄`).
